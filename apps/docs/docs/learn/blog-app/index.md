# Build a Blog App

This learning path builds a real blog admin app with Holo-JS. It is the guided path for users who want to learn the framework in the order they will use it in an application.

The feature docs stay available as reference. This path connects those features into one working app.

## Learning pipeline

```txt
Create project
-> Configure Holo
-> Database and migrations
-> Models and queries
-> Forms and validation
-> Auth
-> Authorization
-> Media uploads
-> Notifications
-> Realtime
-> Testing
-> Deployment
```

## How to use this path

Follow the chapters in order. Each chapter should leave the app in a working state before moving to the next one.

Each chapter includes:

- the app goal for that step
- the files that change
- the commands to run
- the result users should see
- links back to deeper reference docs

## Example app target

The tutorial app is a blog with an admin area:

- public post listing
- posts, categories, and tags
- registration and login
- protected admin screens
- policy-based authorization
- featured image uploads
- notifications for important post changes
- realtime admin updates
- tests and deployment checks

## Source app

The finished example lives in `apps/blog-next`. The learning path teaches that app in build order, so users can compare each chapter with a working implementation.
