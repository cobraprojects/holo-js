# Union cursor pagination filters the union's output, not its branches

`cursorPaginate()` on a union wraps the union in a derived table, `SELECT * FROM (<union>) AS __holo_union_page WHERE <cursor> ORDER BY <outputs> LIMIT n`, and compares cursor values with the first query's output columns. Laravel's `paginateUsingCursor` adds the cursor `WHERE` to each branch instead. That needs Holo to know, for every branch, which column sits at the order column's position. A wildcard hides a branch's physical column order, and a table definition's column order can differ from it. So a branch could be filtered on a different column than the one the union outputs, and the first page would issue a cursor its next page skips rows with (#709). The derived table filters exactly the values the union outputs, so there is nothing to map.

PostgreSQL and MySQL push the outer predicate into each branch. On PostgreSQL 17 and MySQL 8.4, `EXPLAIN ANALYZE` of page two of a two-branch `UNION ALL` over an index on `(tenant, rank, id)` produced the same plan for both shapes: index scans in every branch, the same buffers and cost. Cursor pagination needs output names Holo can address, so it throws `CompilerError` before it runs a query when the first query selects a wildcard Holo can't see into, repeats an output name (compared the way the database compares identifiers), or doesn't select the order column.

A union can return different types under one output. Cursor values are therefore normalized through the column behind the first query's output only when they already read as that column's type, and kept as stored otherwise.

On SQLite, the cursor comparison uses `+"output"`, which drops the column's type affinity, so values compare by storage class the way the union's `ORDER BY` sorts them. The page also selects `typeof(+"output")` for each order column. An integer the SQLite adapter returns as a string, because it is beyond the safe integer range, is encoded in the cursor as `{ "bigint": "<digits>" }` and bound back as a `BigInt`. Without this, a union of an INTEGER branch and a TEXT branch holding numeric-looking strings, such as `2` and `'10'`, `'20'`, `'3'`, skips `'10'`: SQLite's affinity converts the bound cursor value, while `ORDER BY` compares storage classes. Laravel 12's per-branch `WHERE` with the raw cursor parameter has the same skip on SQLite. Holo departs from Laravel here with the user's approval (recorded in ADR 0016).
